# 배치 구현 위치

Spark로 날짜별 원본/도착 데이터를 읽고 Airflow로 일 배치를 실행합니다. 첫 기준선은 평일/주말 × 30분 구간의 P95입니다. 요일별 표본이 충분하면 요일을 분리합니다.

입력 품질·누락 구간·시간표 매칭률을 먼저 집계합니다. 표본 부족 시간대와 관측 공백을 지연 0으로 채우지 않습니다. 열차 혼잡도(지하철혼잡도정보)와 승하차 인원은 집계 기간이 학습·테스트 기간과 겹치는지 확인해 누수를 점검합니다. 정적 CSV는 `reference_rows`의 원본 컬럼을 여기서 해석합니다. PostgreSQL에 버전별 통계와 모델 메타데이터를 저장하는 작업은 후속 구현입니다.
