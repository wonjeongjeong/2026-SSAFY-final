# 서비스 구현 위치

로컬 웹 프로토타입은 [`web/`](web/README.md)에 구현했습니다. 프로젝트 루트에서 `start_web.cmd` 또는 `python services/web/server.py`를 실행하고 http://127.0.0.1:5173 에 접속합니다.

19개 노선 지도·역 검색과 실제 시간표 기반 여러 경로 비교를 제공합니다. EC2를 통해 최신 도착정보와 GTX-A 위치 상태를 조회하고 안전하게 식별한 열차의 후속 시각을 보정합니다. 역별 환승시간과 추가 여유, 앞의 0·1·2대를 보내는 시나리오를 적용해 빠른 도착과 늦은 출발을 탐색합니다. [현재 방식과 미확보 데이터](../docs/live-route-draft.md)를 확인하세요.

후속 API는 FastAPI로 경로 탐색, 후보 열차 평가, 안정/마지노선 출발 시각을 제공합니다. 웹은 공개 역 좌표로 직접 그린 노선도에서 출발·도착·경유를 선택합니다. LLM은 자연어 입력 구조화와 확정된 계산값 설명만 담당합니다.

현재 로컬 서버는 Python 표준 라이브러리로 정적 화면과 JSON API를 제공합니다. 운영용 FastAPI, 학습 모델과 실시간 승강장 혼잡도 연동은 후속 구현입니다. 실시간 매칭·시간표 기준·환승 가정·혼잡 대기 시나리오는 결과에서 구분합니다.
