# 여유 — 실제 시간표와 실시간 경로 초안

```powershell
python -B services/web/server.py --port 5173
```

접속: http://127.0.0.1:5173. `start_web.cmd`로도 실행합니다. Python 3.10 이상이며 외부 패키지는 필요하지 않습니다. 127.0.0.1에만 바인딩하며 종료는 실행 터미널의 Ctrl+C입니다.

## 처음 실행하거나 시간표를 갱신할 때

로컬 PC에 EC2의 `subway-collector` SSH 별칭과 개인 키가 있어야 합니다. 인증키는 EC2에만 둡니다.

```powershell
python -B scripts/fetch_web_timetables.py
python -B scripts/sync_web_timetable.py
```

첫 명령은 EC2에 없는 노선의 유효 시간표를 기존 키·호출 예산으로 추가 수신합니다. 두 번째 명령은 비밀정보 없는 압축 시간표를 `services/web/data/`로 복사합니다. 캐시는 Git에 포함되지 않습니다. 갱신 후 로컬 웹 서버를 재시작합니다. 현재 날짜에 이미 적재된 노선을 강제로 다시 받는 기능은 없으므로 같은 날 시간표 변경 시 별도 유효성 점검이 필요합니다.

## 사용

- 출발역·도착역·목표 도착시각을 선택합니다. 역 입구나 집에서의 이동은 포함하지 않고 승강장 기준입니다.
- 여러 경로를 실제 열차로 계산해 빠른 도착·늦은 출발·여유 있는 출발·환승 적은 경로로 비교합니다.
- 경로 카드를 누르면 열차번호·일반/급행·행선지·출도착 시각·환승 이동 및 대기시간·정보 출처가 표시됩니다.
- 공식 최단 환승시간에 추가 여유와 승차 여유 30초를 더합니다. 역·노선 간 이동시간을 직접 입력할 수 있습니다. 방향별 승강장 실측이 없는 값은 추정으로 표시합니다.
- 혼잡 대기는 각 탑승에서 앞의 0·1·2대를 보내는 사용자 시나리오입니다. 다음 실제 열차로 다시 계산하며 실시간 혼잡도 측정이나 검증된 실패 확률로 표시하지 않습니다.
- 화면을 보고 있을 때 15초마다 다시 계산합니다. 탑승 완료 추적·백그라운드 알림은 아직 없습니다.
- 19개 노선 지도를 확대하거나 역을 눌러 선택할 수 있습니다. 지도 열차는 수집기의 최근 저장 위치이며 오래된 관측은 흐리게 표시합니다. 경로용 실시간 조회와 구분합니다.

## 실제 데이터와 현재 한계

공식 API 시간표 202,008행과 환승 CSV 145행을 확보했습니다. 시간표는 19개 노선이 있으나 현재 **9호선 유효 응답은 38개 지도 역 중 16개 역만 포함**하므로 일부 운행이 탐색에서 빠집니다. 누락 시간표를 합성하지 않습니다.

`live_data.py`는 SSH로 EC2에서 최신 도착정보를 조회하고 필요한 GTX-A 위치 상태를 보완합니다. 요청은 기존 `requests`·원문 gzip·일일 예산에 기록합니다. EC2의 15초 이내 수집 응답을 재사용하고 로컬 성공 응답은 5초 캐시로 공유합니다. 브라우저에 API 키를 전달하지 않습니다. 출퇴근 수집은 위치·도착정보 모두 목표 15초 간격입니다.

열차번호·방향·행선지·운행 발생 시각을 유일하게 연결할 수 있는 신선한 응답만 보정합니다. ETA는 원천 생성 시각 + 남은 초로 계산합니다. 0초·오래된 정보·모호한 식별은 사용하지 않습니다. 현재 추정 지연을 후속 구간에 유지하는 초기 방식이며 학습 모델은 아닙니다. 매칭되지 않은 운행은 실제 시간표를 사용합니다.

탐색은 탑승 횟수별 전방·역방향으로 수행하며 상태별 대안 수와 최대 환승 횟수를 제한합니다. 모든 경로의 전역 최적성이나 실제 도착을 보장하지 않습니다. 다음 날은 요일·유효기간이 맞는 시간표를 사용하고 현재 지연을 다음 날에 적용하지 않습니다. 공휴일은 수집기 `day_type_overrides`를 공유합니다.

전체 설계·출처·범위는 [실시간 경로 초안](../../docs/live-route-draft.md)을 참고하세요.

## 검증

```powershell
python -B -m unittest discover -s services/web -p "test_*.py" -v
python -B -m unittest discover -s tests -q
```

가상 운행 데이터는 테스트 파일에만 있습니다. 실제 화면에는 예시 배차·예시 열차를 제공하지 않습니다.

주요 모듈: `timetable_data.py`(정규화), `prediction.py`(실시간 보정), `journey_search.py`(여러 경로 및 역산), `transfers.py`(환승 정책), `live_data.py`/`live_gateway_remote.py`(실시간 조회), `public/journeys.js`(비교 화면).
