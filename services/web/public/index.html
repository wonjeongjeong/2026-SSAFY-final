HOW IT WORKS

실제 열차를 연결하고, 다시 계산합니다.

유효한 공식 시간표에서 열차별 정차역·행선지·일반/급행을 연결하고, 최신 도착예정 정보 또는 출도착 상태를 안전하게 매칭한 열차의 후속 구간을 보정합니다.

빠른 도착 / 늦은 출발
지금 출발할 때의 빠른 도착과 목표시각에 맞춘 늦은 출발을 별도로 탐색합니다. 환승 횟수와 보관하는 경로 대안 수를 제한하므로 전역 최적해를 보장하지 않습니다.
실시간 추정
정보 생성 시각과 열차번호·방향·행선지를 확인합니다. 현재 지연을 해당 열차의 후속 구간에 유지하는 초기 추정이며 학습 모델은 아닙니다. 매칭되지 않은 열차는 실제 시간표 기준입니다.
환승
공식 최단 이동시간에 추가 여유를 더합니다. 반대 방향 자료를 적용하거나 자료가 없으면 추정으로 표시합니다. 직접 입력한 노선 간 이동시간을 우선합니다.
혼잡 대기
현재는 탑승 때마다 0·1·2대를 보내는 가정입니다. 고정 배차를 더하지 않고 다음 실제 열차로 경로를 다시 계산합니다.
갱신
화면을 보고 있는 동안 30초마다 재계산합니다. API 장애나 최신 관측 부족 시 시간표 기준임을 표시합니다. 시간표의 확보 범위와 일부 운행 누락은 결과에서 확인할 수 있습니다.
